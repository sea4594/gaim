# GAIM redesign: Phase 6 hard gate — genuine cooperative turns

**Blocker:** The currently accepted Storm Engine chassis supplies only two charge edits per round; Phase 5 demonstrates that neither restricting permission to touch charges nor rotating responsibility for sporadic construction gives all four participants dependable consequential involvement. The multiplayer *action economy* is the design problem now.

## Competing structural prototypes

1. **Parallel workstreams (primary).** Two players plan charge alignment while two plan the settlement's immediate reactor/defense allocation; next round rotate. Both workstreams must have independently scarce resources and opposing consequences, not a mere approval click. Inactive workstream seats must choose a future commitment or receive a real, explicitly documented decision; avoid artificial busywork.
2. **Four personal tempo levers.** Each seat contributes a limited, personally replenishing action token every round, with storms and resources *balanced* for 1, 2, 3, and 4 players. Each player can choose between an immediate edit and a future investment; don't simply add four free edits to the two-edit Storm Engine.
3. **Operations-with-a-settlement (pivot challenger).** Retain asymmetric personal card hands, remove passive missions, and allow cards to build one persistent shared objective. No full import of Engine's three upgrade trees.

## Playtest standards

* Simulate full games with rotation-aware competent policy, *but* do not call action count equivalent to agency.
* Include direct independent-contribution ablation: does substituting one seat's decision change a later teammate's optimal plan? If not, the choice is cosmetic.
* Track per-player opportunities, actual decisions, constructive disagreements, ability to explain consequences, and solo feel.
* Test open voice communication, restricted communication *only when justified*, mixed-experience groups, and whether one player can still order everyone around.
* Avoid nonlinear player-count difficulty drift like Operations' original 1 vs 4 win-rate disparity.
* Set an explicit scope budget: no more than one new shared resource and one new step in the round sequence for first prototypes.
* Require a positive human playtest signal before Phase 7 acceptance. If no human playtesting is possible, be explicit that the gate remains open.

**Do not modify shipping rules until the new core wins a complete-system comparison.**
